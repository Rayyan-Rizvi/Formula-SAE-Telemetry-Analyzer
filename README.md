# Formula SAE Telemetry Analyzer

A Python and SQL tool that generates synthetic Formula SAE-style vehicle telemetry, then analyzes it for lap performance, driver inputs, sector times, and vehicle health.

*All telemetry here is synthetic. No Queen's University Racing data is used — see [Synthetic Data](#synthetic-data) below.*

## Why I Built It

I'm on the Electrical & Software Systems subteam at Queen's University Racing, where a lot of the work is testing vehicle software, tracking down faults, and writing up what we find. That process made me want to build the tool from the other direction: something that takes raw sensor output and turns it into the kind of summary an engineer or driver would actually look at after a session.

## Synthetic Data

Every data point in this project is generated by code in `src/`. No Queen's
University Racing data or confidential team information is used anywhere.

The simulated car is a fictional Formula SAE-style vehicle. It is not modelled on any real car, and the numbers it produces should be read as simulated results — the point is to demonstrate the analysis pipeline, not to make claims about vehicle performance.

## Technologies

Python · Pandas · NumPy · SQLite · Jupyter · pytest · Git

## Getting Started

```bash
git clone https://github.com/Rayyan-Rizvi/Formula-SAE-Telemetry-Analyzer.git
cd Formula-SAE-Telemetry-Analyzer

python3 -m venv .venv
```
